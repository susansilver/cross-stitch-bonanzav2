## Starts

I have one new start. It is the Sea Witch by Nora Corbett. One of the reasons why I got this
pattern is because it is smaller than my Mirabilia which is 200 stitches wide. It felt
like moving to this pixie project was a good idea. Not only is it smaller, it also only requires
DMC and beads. I want to do a few of these smaller pieces and work my way up to the Mirabilia. Next, I'll try a pixie that requires krenik and/or watter lillies.
