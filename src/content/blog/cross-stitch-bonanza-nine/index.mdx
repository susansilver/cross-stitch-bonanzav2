Well, for the first time we missed a week. It was intentional. I was hoping two weeks would be enough time to complete
an original design for this cross stitch blog. I'm never pleased using someone else's template. That is because while this one
covers most of my use cases it is not complete. And it is difficult to add things to someone else's code. You end up making things
not work. For a project this large, it makes more sense to start with something new than modify what exists. But, that is great
because I'm able to add several functions on the backend that I needed.

I wanted to focus this blog more on the WIPs and their progress. Making it easy to look at any project and follow it's progression. That
is what draws us to Flosstube. The imagery and the chat. I want to replicate that experience as much as I can in the written word. I
also wanted something that would show off images beautifully. I wanted to take advantage of using high quality photography.

Well, this is what the home page is looking like right now.

## Starts

I did have a new start this month. This pattern by The Witchy Stitcher was a patreon exclusive and I though it was gone forever.
It made an appearance in the her shop and I grabbed it right away. It is called [A Graveyard Wander](https://www.thewitchystitcher.com/product-page/a-graveyard-wander-pdf-pattern).I wish that I had more progress but working on the website
has taken up most of my time. Planning on picking this up again next month. Here is my progress so far.

I am working it as a 40 count and loving it. There is something about working with one strand that I like. I went with a higher
count because I thought it would look more delicate and romantic. The choice of fabric color helps with that as well. I am pleased
with it.
