I fell in love with Jed X Stitch patterns while working on Blueberry Harvest. I wasn't even done with it when I bough this
pattern, Eleven Rabbits (which I've called Elven Rabbits by mistake _lol_.) You guessed it. This pattern features
eleven bunnies and a massive red dragon at the center. It is still on a 40-count Linen which is now my favorite type
of fabric.
